# Product

## Register

brand

## Users

Tech recruiters, hiring managers, and potential freelance clients (Indonesia + international). They skim: 30–90 seconds to decide whether Galih is credible. Secondary: fellow engineers checking him out before a collaboration.

## Product Purpose

Personal portfolio of Galih Priyambodho — Backend & Database Engineer, 7+ years (since 2018), fintech-heavy .NET/SQL work in Indonesia. Success = a recruiter believes the experience is real and reaches out via the contact form or email.

## Brand Personality

Grounded, precise, understated. An experienced backend engineer who lets specifics (transaction systems, EDC devices, query tuning) do the talking. Not flashy, not salesy, never inflated.

## Anti-references

- Template/AI portfolio tells: skill percentage bars, meaningless stat grids, resume-speak verbs ("spearheaded", "robust", "leveraged").
- Inflated claims: "Full-Stack" when the evidence is backend; inconsistent experience numbers.
- Generic SaaS landing-page grammar: eyebrow labels above every section, numbered section markers as decoration.

## Design Principles

1. **Facts over metrics** — real years, real systems, real tools; never invented percentages.
2. **One consistent story** — same title, same numbers, same voice on every page.
3. **Sound like a person** — copy a human engineer would say out loud; concrete over corporate.
4. **Content works without JS** — reveal animations enhance, never gate visibility.
5. **Preserve the existing editorial identity** — warm paper palette is a committed brand choice. Type stack (since 2026-07): Fraunces for display (replaced DM Serif Display, which is a recognizable AI-output default), DM Sans 400+ for body (never 300 — too thin to read), DM Mono for labels. Print-style offset shadows (`--shadow-print`) instead of generic blur drop-shadows; no translateY hover lifts.

## Accessibility & Inclusion

WCAG AA target: body and label text ≥4.5:1 contrast, `prefers-reduced-motion` honored, keyboard-reachable interactive elements, semantic headings.
